🎯 **What:**
This PR addresses the missing test coverage for the `StreamPortfolioValuation` method in the `customerbll` package (`internal/app/customerbll/streams.go`).

📊 **Coverage:**
The added tests cover the following scenarios for `StreamPortfolioValuation`:
- **Invalid Argument**: Missing `portfolio_id`.
- **Successful Upstream**: Properly forwarding events from a mock upstream client stream to a mock client server stream.
- **Upstream Initialization Error**: Graceful fallback to sending a mock ticker loop.
- **Client Stream Error**: Properly propagating errors if sending to the client stream fails.
- **Fallback Behavior**: Properly initiating a ticker and ending successfully after sending fallback events when the upstream client is not configured.
- **Fallback Context Cancellation**: Properly ending the fallback mock event loop when the stream's context is canceled.

✨ **Result:**
Test coverage for the file and method has been increased. Bugs or regressions in this method are now far more likely to be caught by the test suite before deploying.
